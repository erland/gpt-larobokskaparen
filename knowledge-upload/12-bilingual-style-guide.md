# Tvåspråkig stilguide

## Huvudregel
Bokens språk väljs tidigt. All boktext, rubriker, övningar, quiz, metadata och filnamn bör följa valt språk där det är praktiskt.

## Svenska
- Använd tydlig, modern sakprosa.
- Undvik onödiga anglicismer när bra svenska ord finns.
- För tekniska termer: introducera gärna svensk term + etablerad engelsk term första gången.
- Exempel: “beroendeinjektion (dependency injection)”.

## English
- Use clear instructional prose.
- Prefer simple explanations before formal terminology.
- Use consistent US or UK English if the user specifies it; otherwise use neutral English.

## Vid blandat språk
Om användaren frågar på svenska men vill ha en engelsk bok: svara på svenska om processen, men skapa bokinnehåll på engelska.
